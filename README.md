## 📌 Sobre o Repositório

Este repositório reúne os exercícios práticos resolvidos durante a disciplina, organizados por exercício. Os exercícios trabalham com **structs** em C, focando na definição e manipulação de registros de alunos — leitura, alteração e verificação de dados como nome, nota, idade e endereço.

## 🧠 Conceitos Aplicados

| Conceito | Aplicação |
|---|---|
| `struct` | Definição do tipo `Aluno` com campos nome, nota, idade e endereço |
| Passagem por referência | Alteração de dados usando ponteiros |
| `scanf` / `printf` | Leitura e exibição dos dados no terminal |
| Funções | Separação das operações em funções reutilizáveis |
| Condicionais | Verificação e validação dos campos da struct |

## ▶️ Como Compilar e Executar

Com o GCC instalado, para compilar qualquer exercício:

```bash
gcc exercicio-01/struct-aluno.c -o exercicio-01/struct-aluno
./exercicio-01/struct-aluno
```

Ou use o terminal integrado do VS Code — o `tasks.json` já está configurado para compilar automaticamente com `Ctrl+Shift+B`.
